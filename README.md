# Leme Pier

Every agent, one dock.

Leme Pier is a desktop app that finds the AI coding CLIs already installed and signed in on your machine (`claude`, `codex`, `agy`, `opencode`) and lets you use them from one place: a conversation you can continue with another agent or model without starting over, one brief sent to several agents at once, and a plan carried out by a crew of them in parallel. It starts the official CLIs with the sign-ins you already made and sends nothing anywhere itself.

Status: design phase, nothing to install yet. The plan is in [ARCHITECTURE.md](ARCHITECTURE.md).
